# Alice & Mouzinho — Convite de Noivado

Website estático pronto para publicar no GitHub Pages.

**Data:** 31 de Outubro de 2026  
**Hora:** 14h  
**Domínio pretendido:** `alicemouzinho.github.io`

## Publicar no GitHub Pages

1. Crie um repositório público chamado **alicemouzinho.github.io** na conta GitHub `alicemouzinho`.
2. Extraia os ficheiros deste projecto e coloque `index.html`, `style.css` e `script.js` na raiz do repositório.
3. Faça commit/push.
4. No GitHub, abra **Settings → Pages** e escolha a branch principal (`main`) e a pasta `/ (root)`.
5. O endereço será `https://alicemouzinho.github.io/`.

## Antes de publicar

No `index.html`, actualize:
- **Local:** substitua “Local a confirmar”.
- **Confirmação:** altere o link do botão “Confirmar presença” para o seu WhatsApp ou formulário.
- **Programa:** ajuste os horários caso necessário.
- Se tiverem fotos, podem ser adicionadas como uma secção de galeria.

## Estrutura

- `index.html` — conteúdo e estrutura
- `style.css` — design, animações e responsividade
- `script.js` — envelope animado, countdown e calendário

O projecto não precisa de servidor ou backend: funciona como um site estático no GitHub Pages.
